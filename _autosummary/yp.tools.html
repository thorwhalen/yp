yp.tools.latest_release_upload_datetime(releases_data)[source]#

Gets the upload_time of the first item of the latest release from the ‘releases’ data.

Parameters:

releases_data (dict) – A dictionary representing the ‘releases’ value from a PyPI info JSON.

Return type:

str | None

Returns:

A string representing the ‘upload_time’ of the first file of the latest release, or None if the input is empty or malformed.
